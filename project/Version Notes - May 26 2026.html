What's New in v2

Changes since the May 14 handoff
Survey Templates — Voice channel support  New
Added three Voice-only templates: Post-Call IVR CSAT, NPS IVR Phone Survey, and Agent Coaching — Call Quality. Channel column shows plain text (Digital / Voice / Digital, Voice).
Survey Templates — Visual consistency  Updated
Templates page now matches Survey Campaigns styling: count badge in heading, "by owner" under Last Updated, Search by name placeholder, empty state row, and row actions kebab (Edit / Duplicate / Delete).
Survey Templates — Simplified columns  Updated
Removed Digital style, Max Qs, Used by, Owner filter, and action column. Table now shows: Survey template · Channels · Type · AI questions · Last updated.
Info banner spacing & scroll behaviour  Updated
Info banner now has 24px top / 12px bottom margin and scrolls with table content (no longer pinned above the table).
Global header — waffle icon removed  Updated
App-switcher (waffle/grid) icon removed from the top-right utility bar.

How to Open the Prototype

No install or server required
1
Download the file Save Feedback Intelligence (Standalone).html from the shared folder or Git repository.
2
Open in Chrome or Edge Double-click the file or drag it into a browser tab. No localhost needed — the prototype is fully self-contained.
3
Navigate using the left sidebar Use Survey Campaigns, Survey Templates, and VU Score Model to explore all flows. All buttons and actions are interactive.
